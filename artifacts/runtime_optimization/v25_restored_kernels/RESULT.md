## Why total wall went UP (not a real regression)

The G3 PDB recalibration today **overwrote** the multinet schedule at
`scheduled_networks_1yolo_4mlp_2dronet_firesim_hybrid.json` with one
generated by `hybrid_periodic_mosek_yolo` against the calibrated PDB.
That solver runs with `--no-prune-periods`, expanding periodic
instances over the full 400 ms makespan horizon:

- v20b ran: 1 yolo + 4 mlp + 2 dronet = ~210 dispatches
- v25 ran: 1 yolo + 40 mlp + 20 dronet = 826 dispatches

The walker honored every instance in the schedule, so total wall
scales with the number of periodic instances. Per-instance numbers
are the apples-to-apples comparison.

## Correctness improvement is real

The dronet `max_abs_err = 72 → 8` improvement is the biggest result.
Hypothesis: pre-v25 dronet ran scalar relu/maxpool on the rvv_opu
hart. Scalar loops take so long (~200 K cycles for n=23328 relu) that
the next dronet instance starts before the previous finishes,
overwriting shared `buf_dronet_*` intermediate buffers (see issue
#247 root cause). Vectorized restored kernels execute ~50-100x faster,
so dronet instances complete inside their 20 ms band — instance
buffer races dramatically reduced.

A residual `max_abs_err = 8` suggests the race is reduced, not
eliminated. Per-instance pool buffers (task #282) would close the rest.

## HART_ACC

```

v25  rvv_opu  402926  kernel  +  93090 dep_wait = 496856 wall
```

gemmini hart spent 71% of its time in dep_wait — because the rvv hart
is loaded with 5× more periodic work. With v20b-style schedule density
(periodic-pruned), the rvv kernel sum should drop ~5x to ~80 ms, well
below v20b's 133 ms. Tracked under task #287.

## Yolov8 per-instance regression?

yolov8 instance wall 228 ms in v25 vs 157 ms in v20b is a real per-
instance difference (same instance count: 1). Possible causes:
- Schedule routes more yolov8 ops to the now-congested rvv hart
  (which is doing 5x periodic work)
- Or v25 yolov8 has slower kernel picks somewhere

Need to dig into the v25 yolov8 dispatch trace to attribute the +71 ms.
